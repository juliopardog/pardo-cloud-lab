The problem

Create a repeatable path from source control to a self-hosted website without relying on manual file transfers.

The solution

GitHub Actions assigns a workflow job to the Linux runner. The runner executes deployment tasks on the host; Docker and Nginx serve the static application.

Architecture

git→Actions→Nginx

Conceptual architecture. Select Explore infrastructure for the interactive lab deployment path.

Explore infrastructure ↗

Implementation

  1. Prepare the Linux Mint host and Docker runtime.
  2. Install the GitHub Actions runner as a service under a separate account.
  3. Use the pardo-deploy runner label to target deployment jobs.
  4. Deploy static application assets and verify the HTTP response.
