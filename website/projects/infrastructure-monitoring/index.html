The problem

Make host and application behavior observable through a safe, read-only public interface.

The solution

Unprivileged host collection and a separate fixed-query container collector publish sanitized snapshots. The browser cannot administer the host.

Architecture

Host→Metrics→Charts

Conceptual architecture. Select Explore infrastructure for the interactive lab deployment path.

Explore infrastructure ↗

Implementation

  1. Collect aggregate host counters every fifteen seconds.
  2. Read website container health through a separate restricted collector.
  3. Cache public GitHub deployment workflow runs.
  4. Record one sample per minute with seven-day retention.
